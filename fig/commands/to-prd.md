# /fig:to-prd

Synthesizes a completed grilling session into a structured PRD document.

## Usage

```
/fig:to-prd     # Convert the current grilling session into a PRD
```

Typically run after `/fig:grill-me` has resolved all ambiguities.

Read and follow [`skills/fig/to-prd/SKILL.md`](../skills/fig/to-prd/SKILL.md).
