# /fig:handoff

Compact the current conversation into a handoff document so a fresh agent can continue the work.

## Usage

```
/fig:handoff                          # Full handoff of the current session
/fig:handoff [next session focus]     # Tailor the doc to what comes next
```

Read and follow [`skills/fig/handoff/SKILL.md`](../skills/fig/handoff/SKILL.md).
