# /fig:to-backlog

Break a plan, spec, or PRD into independently-grabbable issues on the project issue tracker using tracer-bullet vertical slices.

## Usage

```
/fig:to-backlog                  # Break current plan/PRD into issues
/fig:to-backlog [issue number]   # Break a specific issue into sub-issues
/fig:to-backlog [issue URL]      # Break an issue referenced by URL
```
